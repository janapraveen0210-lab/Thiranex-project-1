# Sales & Revenue Analysis Dashboard

## Project Overview

This project is an interactive Sales & Revenue Analysis Dashboard developed using Python, Pandas, Streamlit, and Plotly. The dashboard helps analyze sales performance, revenue trends, product performance, category-wise sales, and regional sales.

## Features

* Interactive dashboard using Streamlit
* KPI tracking:

  * Total Sales
  * Total Profit
  * Total Quantity Sold
* Monthly Revenue Trend Analysis
* Top 10 Products by Revenue
* Sales by Category Visualization
* Sales by Region Visualization
* Region and Category Filters
* Dataset Preview

## Technologies Used

* Python
* Pandas
* Streamlit
* Plotly

## Dataset

The project uses the Superstore Sales dataset containing:

* Orders
* Customers
* Products
* Sales
* Profit
* Regions
* Categories

## How to Run

1. Clone the repository:
   git clone <repository-url>

2. Navigate to the project folder:
   cd Thiranex-project-1

3. Install required packages:
   python -m pip install streamlit pandas plotly

4. Run the dashboard:
   python -m streamlit run app.py

## Dashboard Insights

The dashboard enables users to:

* Monitor sales performance
* Identify top-performing products
* Analyze category-wise revenue
* Compare regional sales
* Track monthly revenue trends
